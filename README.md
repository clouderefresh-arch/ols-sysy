# ОЛС

Сайт ООО «ОЛС»: перевозка фармацевтической продукции с контролем температуры.

Тексты взяты из описания компании. Телефон, почта и реквизиты в нём не указаны, поэтому на сайте их нет, а форма собирает текст заявки локально и не отправляет его на сервер.

Открыть: `index.html` или любой статический сервер из корня репозитория.
